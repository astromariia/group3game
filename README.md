To play Avenge of the Elf King, you must start up the exe file and press play to begin the game. Throughout the game you must beat the Demon King's henchmen
and kill the Demon King to avenge your father. The game ends when you kill the Demon King.

Should you choose to download our source code, clone the repository, and navigate to roguelike-concept folder, and open the project.godot file in the Godot game engine. Then navigate to the play button in the top right corner and press play. The game should begin once you do that.
